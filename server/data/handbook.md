# 校园办事手册（第一版样例数据）

> 本文件是演示用的小型业务知识库，共 5 条高频办事事项。
> 格式约定：`## 事项标题`，紧跟「- 字段: 值」形式的元信息，
> 再用 `### 办理步骤 / ### 需要材料 / ### 补充说明` 三个小节描述细节。
> 检索层解析的就是这个格式，新增一条事项只需按同样结构追加。

## 宿舍空调报修

- 关键词: 空调, 报修, 维修, 不制冷, 漏水, 异响, 宿舍, 电路, 跳闸
- 归属部门: 后勤保障中心
- 办理时限: 提交后 24 小时内联系，48 小时内上门
- 办理入口: 企业微信 → 校园服务 → 后勤报修 → 选择宿舍楼栋与房间号

### 办理步骤

1. 在企业微信「后勤报修」里选择「空调类故障」，填写楼栋、房间号与故障现象。
2. 上传一张故障照片（例如漏水位置、外机铭牌），便于师傅带件上门。
3. 提交后记录工单号，师傅上门前会电话联系，请保持手机畅通。
4. 维修完成后在工单里点「已解决」；同一问题 7 天内复发可凭工单号免费返修。

### 需要材料

- 宿舍楼栋与房间号
- 故障现象描述（不制冷 / 漏水 / 异响 / 自动关机）
- 故障照片 1 张

### 补充说明

- 空调属于学校资产，请勿自行拆机或加注冷媒，否则维修费用需自理。
- 夜间 22:00 后的紧急漏水，可拨打后勤值班电话（见宿舍门后张贴的应急联系表）。
- 如果整层都停电或跳闸，先在本楼值班室确认是否为楼层总闸问题，再报修。

## 在读证明开具

- 关键词: 在读证明, 学籍证明, 证明, 开具, 打印, 盖章, 在读
- 归属部门: 教务处（学籍管理科）
- 办理时限: 自助打印即时取；人工盖章 1 个工作日
- 办理入口: 教务系统 → 证明打印 → 在读证明（自助机位于图书馆一楼大厅）

### 办理步骤

1. 登录教务系统，在「证明打印」中选择「在读证明」，核对姓名、学号、专业与学制。
2. 选择用途：升学、实习、签证、银行等，系统会按用途生成对应抬头。
3. 到图书馆一楼自助打印终端刷校园卡打印，机器自动加盖电子章。
4. 需要纸质红章的，把打印件交教务处窗口加盖实体章（可代办，需带双方校园卡）。

### 需要材料

- 校园卡（自助机刷卡）
- 学生证（人工盖章时核对）
- 如需英文版，请同时勾选「中英文对照」

### 补充说明

- 在读证明只能证明当前在读状态，不含成绩信息；需要成绩单请走「成绩单打印」。
- 毕业年级如需「预毕业证明」，需先由学院教务员确认毕业资格。

## 校园卡挂失与补办

- 关键词: 校园卡, 饭卡, 挂失, 补办, 丢卡, 充值, 刷卡, 补卡
- 归属部门: 信息化中心 · 校园卡服务部
- 办理时限: 挂失即时生效；补卡现场制卡约 10 分钟
- 办理入口: 企业微信 → 校园卡 → 挂失/补卡；或前往学生服务中心 2 号窗口

### 办理步骤

1. 发现丢卡立刻在企业微信「校园卡」里点「挂失」，冻结消费与门禁权限。
2. 确认卡片找回后可在同一页面「解挂」；确认丢失则申请补卡。
3. 带身份证或学生证到学生服务中心 2 号窗口现场制卡，工本费从卡内余额或线上支付。
4. 新卡需在食堂任意刷卡机或自助终端上「激活」一次，门禁权限 30 分钟内同步。

### 需要材料

- 身份证或学生证
- 补卡工本费（以窗口公示标准为准）

### 补充说明

- 挂失前产生的消费无法追回，丢卡后请第一时间挂失。
- 原卡余额会在补卡后自动转入新卡，一般即时到账。
- 临时卡（访客卡）不能补办，仅限当日使用。

## 教室与活动场地借用

- 关键词: 教室, 场地, 借用, 申请教室, 活动室, 会议室, 社团活动, 教室预约
- 归属部门: 教务处（教室管理）／学工部（学生活动场地）
- 办理时限: 教学用教室提前 3 个工作日；学生活动场地提前 5 个工作日
- 办理入口: 教务系统 → 教室借用申请；学生活动走企业微信 → 学工服务 → 场地预约

### 办理步骤

1. 先查空闲教室：教务系统「教室查询」按时间段筛选可用教室。
2. 填写借用申请：用途、人数、时间段、是否需要多媒体设备。
3. 提交后由所在学院教务员审核，教学用途优先级高于活动用途。
4. 审核通过后到楼宇管理员处领取钥匙或门禁授权，使用完毕复原桌椅并关灯关空调。

### 需要材料

- 借用申请表（系统内在线填写）
- 活动类借用需附指导老师意见
- 100 人以上活动需附安全预案

### 补充说明

- 教室不得用于商业宣传、收费培训等与教学无关的活动。
- 连续借用超过 3 天需报教务处备案。
- 临时取消请至少提前 1 天在系统里撤销，避免占用资源被记入信用记录。

## 校园网故障与账号问题

- 关键词: 校园网, 网速, 断网, 上网, wifi, 无线, 密码, 账号, 认证失败, 网络
- 归属部门: 信息化中心 · 网络运维部
- 办理时限: 线上报障 4 小时内响应
- 办理入口: 企业微信 → 网络报障；或自助服务门户 → 校园网 → 故障申报

### 办理步骤

1. 先自助排查：确认是否欠费、是否超过设备数上限（默认 3 台）、尝试重新认证。
2. 修改密码：自助服务门户 → 账号安全 → 修改上网密码，修改后 5 分钟内生效。
3. 仍然无法上网，提交报障工单，填写所在楼栋、房间号、设备 MAC 地址与错误提示截图。
4. 运维人员远程排查后如需上门，会电话预约时间。

### 需要材料

- 学号 / 工号
- 所在楼栋与房间号
- 设备 MAC 地址与报错截图

### 补充说明

- 校园网账号仅限本人使用，共享账号会被系统自动封禁 24 小时。
- 宿舍区网络由运营商合作建设，若为宽带账号问题请先联系对应运营商。
- 教学区无线信号弱可提交「信号覆盖」专项工单，由运维现场勘测。
