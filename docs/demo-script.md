# CampusPilot 演示视频脚本（5–8 分钟）

- 目标时长：**7 分 55 秒**（按本稿语速录制，落在 5–8 分钟区间内）
- 录制对象：线上演示环境 <http://47.96.20.128:8787>（也可用本机 `npm start` 的 `http://localhost:8787`，界面一致）
- 语言：普通话；口播稿可逐字照念，不必临场组织语言
- 结构：项目介绍 → 核心功能演示（首页引导、带引用问答、路径决策、知识库登录与上传、超限提示）→ AI 技术亮点 → 收尾

> 录制前先完成下面「一、录制前准备」的全部事项，否则上传与超限两段会没有可用数据。

### 1.3 待上传示例文档（复制保存为 `图书馆研讨间预约.md`）

```markdown
第一章 空间与预约

图书馆三层研讨间面向在校学生开放，用于小组讨论、课程项目与竞赛备赛，不得用于商业活动或长期占位。
```

## 三、附录：录制要点

### 3.1 画面与文件

| 项 | 要求 |
| --- | --- |
| 分辨率 | 1920×1080 或更高，16:9；不要用 720p 或手机竖屏 |
| 帧率 | 30 fps 即可，50/60 fps 也可以但文件更大 |
| 编码与封装 | H.264 + AAC，封装为 `.mp4`；码率 8–12 Mbps |
| 录制工具 | OBS Studio（窗口捕获 + 麦克风）、或系统自带录屏后转码 |
| 浏览器 | Chrome，缩放 100%，隐藏书签栏与扩展图标；关闭系统通知与聊天软件弹窗 |
| 鼠标 | 移动放缓，点击前停顿 0.3 秒；不要快速晃动或遮挡正文 |

### 3.2 声音

- 普通话，吐字清楚；用领夹麦或耳机麦，不要用笔记本内置麦直接录。
- 采样率 44.1 kHz 或 48 kHz；口播与画面误差控制在 0.2 秒内，建议先录画面、再对口播。
- 环境安静，关闭风扇与键盘声；每段重录时整段替换，不要只补一句。

### 3.3 字幕

- 建议配硬字幕或外挂 `.srt`，与口播稿逐句对应；单行不超过 20 个汉字，最多两行。
- 专有名词统一写法：CampusPilot、BM25、SSE、Mock、50 MB、demo / campus2026。
- 数字与单位之间留空格：`50 MB`、`120,000 tokens`、`7 分 55 秒`。

### 3.4 常见问题与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 回答很久不出现 | 公网模型偶发慢，或触发 30 秒超时 | 等 5 秒；仍无输出则重录该段，或改用本机 mock 模式录制 |
| 提示「今日次数已用完」 | 单 IP 当日超过 60 次 | 在服务器 `pm2 restart campuspilot` 清零进程内计数后重录 |
| 提示「请求过于频繁」 | 一分钟内超过 20 次 | 等 60 秒，或重启进程 |
| 上传返回 401 | 登录状态过期（2 小时） | 重新用 demo / campus2026 登录 |
| 上传返回 422 | PDF 是扫描件，抽不出文字 | 换用本文档的 Markdown 示例 |
| 页面刷新 404 | 服务端版本过旧，未含 SPA 回退 | 按 README 3.6 的更新流程拉到最新 `main` 并重新构建、重启，确认 `/upload`、`/chat` 直接访问返回 200 后重试 |

### 3.5 成片检查

- [ ] 总时长在 5–8 分钟之间（本稿约 7 分 55 秒）
- [ ] 开场 15 秒内出现项目名与一句话定位
- [ ] 至少一次完整问答，且展开过引用原文
- [ ] 出现路径决策：知识库作答可见，且展示过转人工与拒答中的至少一条（本稿两条都演示）
- [ ] 出现登录、上传、确认入库、新文档被检索命中的完整链路
- [ ] 出现 50 MB 超限提示
- [ ] AI 部分讲到了检索、引用、流式与成本护栏
- [ ] 1080p 以上、MP4、普通话、字幕与口播一致
